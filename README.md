Code for the simulation framework described in the article:
An individual-based simulation framework exploring the ecology and mechanistic underpinnings of larval crowding in laboratory populations of Drosophila
Authors: Srikant Venkitachalam, Amitabh Joshi
Journal of Theoretical Biology, 2026

Each figure's generating file is added as a separate .py file. 
In case loading data is required, the data are present in the 'Results' folder.
In case the user wishes to generate their own data, please run the MultiRun.py file. This will overwrite the files in the Results folder.
